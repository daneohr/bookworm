# Bookworm 
A library management TUI built in Rust

Built for the sole purpose of helping me learn and practice Rust, including ownership/borrowing systems, TUI state rendering, and file I/O.

## To Run:
1. Clone this repo
2. Make a copy of the `src/library.example.toml` as `library.toml` (You can run something like `cp src/library.example.toml src/library.toml`
3. Run `cargo run`
> [!Warning]
> The compiler will throw warnings as this is a work-in-progress
